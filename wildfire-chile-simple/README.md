# Wildfire in Chile 2024

A simple website made with three files:
- `index.html` — page structure
- `styles.css` — design and colours
- `script.js` — four speaker scripts and buttons

## Open in VS Code
1. Extract this ZIP file.
2. Open the `wildfire-chile-simple` folder in VS Code.
3. Open `index.html`.
4. For a live preview, install the Live Server extension, right-click `index.html`, and choose **Open with Live Server**.

## Upload to GitHub
Create a new empty repository on GitHub called `wildfire-in-chile-2024`. Then open the VS Code terminal inside this folder and run:

```bash
git init
git add .
git commit -m "Add Wildfire in Chile presentation"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/wildfire-in-chile-2024.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Publish with GitHub Pages
On GitHub, open the repository → **Settings** → **Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.

For later changes:
```bash
git add .
git commit -m "Update website"
git push
```
